# Azure-Soc-Lab 

## Project Overview 
This is a hands-on cybersecurity lab built using Microsoft Azure and Microsoft Sentinel to explore cloud security monitoring, log collection, threat detection, and incident investigation.

## Objectives
- Build a cloud-based security monitoring environment
- Collect and analyze Windows security event logs
- Write Kusto Query Language (KQL) queries to identify suspicious activity
- Configure security alerts and investigate simulated incidents
- Gain practical experience with Microsoft Sentinel and Azure security tools

## Technologies
- Microsoft Azure
- Microsoft Sentinel
- Windows Virtual Machines
- Log Analytics Workspace
- Kusto Query Language (KQL)
